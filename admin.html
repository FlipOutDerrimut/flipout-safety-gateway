⚙ Live System Sync Steps: Manual Webhook Mapping

If automation fails to deploy the webhooks directly into the partner environment due to access permission profiles, map the live event trigger manually:

  • Log into the targeted corporate workspace on **Deputy** with admin privileges.
  • Click your **Profile Icon** in the top right menu block and choose **System Settings**.
  • Open **Integrations** on the sidebar control list and select **Webhooks**.
  • Ensure a payload target entry is registered pointing to: https://.../webhook
  • If absent, select **New Webhook**, assign the trigger behavior event rule type to Timesheet.Insert, paste the endpoint target link string, and save changes.
