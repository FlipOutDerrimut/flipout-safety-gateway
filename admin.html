➔ Next Steps: Webhook Verification Blueprint

While the system attempts to build webhooks programmatically, changes in Deputy security layouts can sometimes obstruct automated triggers. Use these steps to guarantee your new location is active:

  • Log directly into the newly added business profile inside Deputy using an admin account.
  • Navigate to Global Settings > Integrations > Webhooks.
  • Confirm that an active entry exists targeting: https://.../webhook
  • If no webhook is present, click New Webhook, set the event topic to Timesheet.Insert, and paste the endpoint URL above into the address target box. Save and enable it.
